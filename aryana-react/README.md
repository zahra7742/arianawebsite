# سایت آریانا کارت (AryanaPay)

صفحه‌ی معرفی (لندینگ) آریانا کارت؛ تک‌صفحه، فارسی و راست‌چین، ساخته‌شده با **React 19** و **Vite**.

این پوشه (`aryana-react`) نسخه‌ی اصلی سایت است. پوشه‌ی کناری `../aryana` نسخه‌ی قدیمی HTML/CSS/JS است که فقط برای مقایسه نگه داشته شده و دیگر استفاده نمی‌شود.

## اجرای پروژه

**پیش‌نیاز:** Node.js نسخه‌ی ۲۰ یا بالاتر (پروژه با Node 24 تست شده است).

بار اول، داخل همین پوشه کتابخانه‌ها را نصب کنید:

```
npm install
```

### اجرا هنگام توسعه

یکی از این سه راه:

| راه | کار |
|---|---|
| دوبار کلیک روی `start.bat` | اگر لازم باشد نصب می‌کند، سرور را بالا می‌آورد و مرورگر را باز می‌کند |
| `npm run dev` در همین پوشه | سرور توسعه روی http://localhost:5173 |
| `npm run dev` در پوشه‌ی بالایی (`C:\project\aryana`) | همان، از ریشه‌ی پروژه (با `package.json` ریشه) |

با هر ذخیره‌ی فایل، صفحه خودش به‌روز می‌شود.

> فایل `index.html` را با دوبار کلیک (آدرس `file://`) باز نکنید؛ صفحه سفید می‌ماند. پروژه‌ی Vite فقط از طریق سرور اجرا می‌شود.

### دستورها

| دستور | کار |
|---|---|
| `npm run dev` | سرور توسعه |
| `npm run build` | ساخت خروجی نهایی در پوشه‌ی `dist` |
| `npm run preview` | اجرای همان خروجی نهایی روی http://localhost:4173 برای تست |
| `npm run lint` | بررسی کد با oxlint |

```

├─ server/

   ├─ components/          هر بخش صفحه یک فایل
```

## محتوا و متن‌ها

بیشتر متن‌ها در [`src/data/content.js`](src/data/content.js) هستند، به شکل لیست. کامپوننت روی لیست حلقه می‌زند، پس برای افزودن یک مورد فقط یک خط اضافه کنید:

```js
export const faqs = [
  { q: 'سوال؟', a: 'جواب.' },
  // مورد جدید را این‌جا اضافه کنید
]
```

- بین آیتم‌ها ویرگول لازم است.
- متن بین دو `'` می‌آید؛ اگر خود متن `'` داشت، دورش را با `"` ببندید.
- عنوان هر آیتم (`title`، `q`، `label`) باید در لیست خودش یکتا باشد، چون React از آن به‌عنوان کلید استفاده می‌کند.

### تصاویر

## استایل، رنگ‌ها و آیکون‌ها

همه‌ی استایل‌ها در [`src/styles.css`](src/styles.css) هستند. هر بخش با یک کامنت شروع می‌شود (مثلاً `/* Contact form */`)؛ برای پیدا کردن استایل یک بخش، اسم آن را با Ctrl+F جستجو کنید. استایل‌های بخش‌هایی که بعداً اضافه شده‌اند در انتهای فایل هستند.

### رنگ‌ها و مقادیر پایه

بالای `styles.css` در `:root` تعریف شده‌اند و همه‌جا با `var(...)` استفاده می‌شوند:

| متغیر | مقدار | کاربرد |
|---|---|---|
| `--navy` | `#1a3b66` | رنگ اصلی برند |
| `--navy-2` | `#12294a` | تیترها |
| `--blue` | `#2962a8` | لینک‌ها و حالت فعال |
| `--yellow` | `#e19c26` | طلایی برند، دکمه‌ی اصلی |
| `--muted` | `#5b6b82` | متن‌های توضیحی |
| `--bg` | `#f8f9fa` | پس‌زمینه‌ی کادرها |
| `--line` | `#d0d7dd` | خطوط و حاشیه‌ها |
| `--radius` | `16px` | گردی گوشه‌ی کادرها |

فونت‌ها (Vazirmatn برای فارسی، Poppins برای اعداد و لاتین) از Google Fonts در `index.html` لود می‌شوند.

### عرض صفحه و نقاط شکست

- عرض محتوا: `.container` با حداکثر **۱۲۴۰ پیکسل** و ۴۰ پیکسل فاصله از هر طرف (در موبایل ۱۶ پیکسل).
- نقاط شکست اصلی: `980px` (تبلت؛ بیشتر چیدمان‌ها یک‌ستونه می‌شوند)، `760px` (موبایل) و `380px` (موبایل کوچک).

### آیکون‌ها

همه‌ی آیکون‌ها در یک «اسپرایت» SVG در ابتدای `<body>` فایل `index.html` هستند، هر کدام یک `<symbol id="i-…">`. در کد با کامپوننت `Icon` استفاده می‌شوند:

```jsx
<Icon name="download" className="ic" />   // از symbol با id="i-download"
```

برای آیکون جدید، یک `<symbol id="i-اسم">` به `index.html` اضافه کنید.

## انیمیشن‌ها و اسکرول

### ظاهر شدن بخش‌ها (`useReveal`)

بخش‌هایی که در لیست `revealSel` در [`src/hooks/useReveal.js`](src/hooks/useReveal.js) هستند، هنگام رسیدن به صفحه نرم ظاهر می‌شوند. شکل حرکت در CSS است (کلاس‌های `.reveal` و `.reveal.in`). برای این‌که بخشی انیمیشن بگیرد، کلاسش را به `revealSel` اضافه کنید.

### بخش سه‌مرحله‌ای (`Journey.jsx`)

این بخش با **GSAP ScrollTrigger** کار می‌کند و چهار حالت دارد که خودکار انتخاب می‌شوند:

| حالت | چه زمانی | رفتار |
|---|---|---|
| `PinnedJourney` | دسکتاپ (بیشتر از ۹۸۰px) | بخش زیر هدر ثابت می‌ماند؛ با اسکرول، متن، تصویر داخل گوشی و نشانگر خط وسط هم‌زمان عوض می‌شوند؛ گوشی در هر مرحله به طرف دیگر می‌رود |
| `MobilePinnedJourney` | موبایل و تبلت | بخش ثابت می‌ماند؛ قاب گوشی ثابت است و صفحه‌ی داخلش اسکرول می‌شود (نوار وضعیت و منوی پایین ثابت)، متن بالا و خط کنار گوشی هم‌زمان حرکت می‌کنند |
| `StaticJourney` | دسکتاپ با «کاهش حرکت» | سه ردیف ثابت، یک‌درمیان |
| `MobileJourney` | موبایل با «کاهش حرکت» | سه بخش عادی زیر هم، بدون ثابت ماندن |

«کاهش حرکت» همان تنظیم سیستم‌عامل است (در ویندوز: *Settings → Accessibility → Visual effects → Animation effects*). اگر خاموش باشد، بخش عمداً بدون انیمیشن نمایش داده می‌شود.

نکته‌های فنی:

- **تصاویر:** قاب گوشی یک PNG شفاف است و سه اسکرین‌شات زیر آن قرار می‌گیرند. موقعیت صفحه‌ی گوشی با درصدهایی که از روی خود تصویر اندازه گرفته شده تنظیم شده (کامنت‌های بالای `.jr-device` در CSS). اگر قاب را با تصویر دیگری عوض کنید، این درصدها باید دوباره اندازه‌گیری شوند.
- **طول اسکرول:** هر حالت ثابت به اندازه‌ی دو برابر ارتفاع صفحه طول می‌کشد (`end: … window.innerHeight * 2` در `Journey.jsx`).
- **ارتفاع هدر:** ثابت‌ها زیر هدر قرار می‌گیرند؛ عدد آن در `HEADER_H = 73` تعریف شده. اگر ارتفاع هدر عوض شد، این عدد و `73px`های CSS همین بخش را هم عوض کنید.
- **پاک‌سازی:** GSAP از `useLayoutEffect` و `gsap.context` استفاده می‌کند و هنگام عوض شدن حالت (مثلاً کوچک کردن پنجره) همه‌چیز را پاک می‌کند. دور بخش ثابت یک `div.jr-pin-wrap` هست که نباید حذف شود؛ بدون آن React هنگام عوض شدن حالت خطا می‌دهد.

### کاروسل مقالات

با انگشت یا تاچ‌پد به‌صورت عادی اسکرول می‌شود و با ماوس هم قابل کشیدن است (`useDragScroll`).

## فرم درخواست و ذخیره‌ی اطلاعات

فرم در [`src/components/ContactForm.jsx`](src/components/ContactForm.jsx) است: نام، موبایل، نوع درخواست (فرد / سازمان) و توضیحات. نام حداقل ۳ حرف و موبایل ۱۱ رقمی با شروع `09` لازم است؛ عدد فارسی هم پذیرفته می‌شود.

با ثبت، اطلاعات به‌صورت JSON با `POST` به آدرس `/api/contact` فرستاده می‌شود:

```json
{ "name": "…", "mobile": "09123456789", "type": "individual", "message": "…" }
```

### ذخیره در حالت فعلی

[`server/contactCsv.js`](server/contactCsv.js) یک افزونه‌ی Vite است که همین آدرس را جواب می‌دهد، اطلاعات را دوباره بررسی می‌کند و در **`C:\project\aryana\submissions.csv`** (پوشه‌ی بالایی) ذخیره می‌کند. این فایل با اکسل باز می‌شود و متن فارسی درست نمایش داده می‌شود.

> این ذخیره **فقط** با `npm run dev` یا `npm run preview` روی همین کامپیوتر کار می‌کند. پوشه‌ی `dist` که روی هاست می‌رود سرور ندارد و فرم آن‌جا خطای «ارسال انجام نشد» می‌دهد.

### وصل کردن به سرور واقعی

یک فایل `.env` در همین پوشه بسازید:

```
VITE_FORM_ENDPOINT=https://example.com/api/requests
```

سرور را خاموش و روشن کنید (و برای خروجی نهایی دوباره build بگیرید). از آن پس فرم به این آدرس می‌فرستد؛ سرور باید با کد ۲۰۰ جواب بدهد، وگرنه پیام خطا نمایش داده می‌شود.

## تغییرات رایج

| می‌خواهید… | کجا |
|---|---|
| متن، سوال، مقاله یا لینک منو را عوض کنید | `src/data/content.js` |
| تیتر یا متن یک بخش خاص | فایل همان بخش در `src/components/` |
| رنگ برند | متغیرهای `:root` در بالای `src/styles.css` |
| عرض کل صفحه | `.container` در `src/styles.css` |
| ترتیب بخش‌ها یا حذف یک بخش | `src/App.jsx` |
| سرعت یا شکل انیمیشن ظاهر شدن | `.reveal` در `styles.css` و `src/hooks/useReveal.js` |
| طول اسکرول بخش سه‌مرحله‌ای | `window.innerHeight * 2` در `src/components/Journey.jsx` |
| سرعت جابه‌جایی گوشی در دسکتاپ | `transition` در `.jr-phone-slot` در `styles.css` |
| فیلد جدید در فرم | `emptyForm`، JSX و `submitRequest` در `ContactForm.jsx` (و اعتبارسنجی در `server/contactCsv.js`) |
| آیکون جدید | یک `<symbol>` در `index.html` |

### اضافه کردن بخش جدید

1. فایل `src/components/NewSection.jsx` بسازید که یک `<section className="container …">` برمی‌گرداند.
2. آن را در `App.jsx` ایمپورت کنید و در جای دلخواه داخل `<main>` بگذارید.
3. استایلش را با یک کامنت عنوان به انتهای `styles.css` اضافه کنید.
4. اگر انیمیشن ظاهر شدن می‌خواهد، کلاسش را به `revealSel` اضافه کنید.

## پیش از انتشار

این موارد در کد یا تصاویر فعلی هست و باید پیش از انتشار عمومی بررسی شوند:

- **تصاویر با برند یا محتوای دیگر:**
  - `app-phone.webp` (بخش «همه چیز در یک اپلیکیشن») موکاپ اپ **Chime** است با مبالغ دلاری.
  - روی کارت و صفحه‌ی گوشی در `features-center.webp` و اسکرین‌شات‌های `journey/` نام برند **ArianaPay** (و «ایرناپی») نوشته شده، نه AryanaPay.
  - لوگوی **Mastercard** روی کارت در `features-center.webp` آمده است.
- **لینک‌ها:** بسیاری از دکمه‌ها و لینک‌ها (فروشگاه‌های اپ، کارت‌های امکانات، شبکه‌های اجتماعی، فوتر) هنوز به `#` اشاره می‌کنند.
- **فرم:** روی هاست واقعی به یک سرور وصل نیست (بخش فرم را ببینید).
- **اطلاعات شخصی:** `submissions.csv` شماره موبایل واقعی آدم‌ها را دارد؛ اگر پروژه در گیت قرار گرفت، آن را به `.gitignore` اضافه کنید و منتشرش نکنید.
- **حجم تصاویر:** چهار تصویر بخش سه‌مرحله‌ای PNG هستند (حدود ۱.۱ مگابایت با هم)؛ تبدیل به WebP صفحه را سبک‌تر می‌کند.
- **کد QR** در بخش اپلیکیشن فعلاً یک الگوی نمایشی است، نه QR واقعی.
